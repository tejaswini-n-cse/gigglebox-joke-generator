# GiggleBox — Random Joke Generator

A responsive, **frontend-only** joke generator made with HTML, CSS and vanilla JavaScript.

## Features
- Fetch random jokes from JokeAPI.
- Filter jokes by category (Any, Programming, Miscellaneous, Pun, Spooky and Christmas).
- Support both one-part and two-part jokes.
- Copy the current joke to the clipboard.
- Save and remove favourite jokes.
- Persist favourites in browser `localStorage`.
- Responsive desktop and mobile layout.

## Run locally
1. Open this folder in VS Code.
2. Start the page using Live Server, or open `index.html` in a modern browser.
3. Select a category and click **Tell me a joke**.
4. Use **Copy** or **Save favourite**. Favourites remain saved in that browser.



No backend or API key is required. An internet connection is needed to fetch jokes. Clipboard access generally requires localhost or HTTPS.
